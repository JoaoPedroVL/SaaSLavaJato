# Fotos do site

Coloque aqui as imagens reais do lava-jato. Se algum arquivo não existir, o site
mostra um fundo ilustrativo no lugar (não quebra).

| Arquivo | Onde aparece | Tamanho ideal |
|---|---|---|
| `antes.jpg` | metade esquerda do slider "Antes e depois" | 1000×1500 (2:3), foto do carro sujo |
| `depois.jpg` | metade direita do slider "Antes e depois" | 1000×1500 (2:3), **mesmo enquadramento** do antes |
| `og.jpg` | preview ao compartilhar no WhatsApp/Instagram | 1200×630 |

Dica para o antes/depois: tire as duas fotos do mesmo ângulo, mesma distância e
mesma luz. É isso que faz o slider funcionar.

As fotos atuais vieram de `referencias/` e já estão recortadas no mesmo
enquadramento. Troque pelas fotos do lava-jato quando tiver.
